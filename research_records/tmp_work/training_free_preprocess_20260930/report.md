# 学習なしの前処理：最初の比較

2026-09-30。ユーザー指定に従い、教師データ・事前学習モデルを使わない画像処理を基本方針にした。4ページ・既知の14 ROIで、3種類の局所しきい値処理を実行し、凍結済みv1・現在のv3と目視比較した。手動アノテーションや拡散復元は実施していない。

[比較ビューア](index.html)から、原画像・分類入力・v1の前景・選択方式の前景を同じ座標で見られる。原画像クリックで512×512画素に拡大でき、白黒マスクやv1との差分にも切り替えられる。[研究方針](../preprocessing_research_direction_20260930.md)

## まず確認できたこと

| 場所 | 所見 |
|---|---|
| [枕草子の薄い筆画](200017197_00008_0/roi_01.png) | v1 ACE CSCが取りこぼしていた左中段の短い筆画と、下の大きなループの細線が、3種類のSauvolaで前景に入る。原画像に直接Sauvolaをかけるだけでも拾える。このROIだけで局所背景補正や多数決の追加効果を主張しない。 |
| [hnsdの水染み・薄い文字](hnsd001_011/roi_01.png) | v3で欠損が増えていた領域の文字は、局所しきい値でも多くが前景に入る。ただし、かすれや薄い筆画の欠損は残る。 |
| [濃い茶色の斑点](hnsd001_011/roi_02.png) | 3種類のSauvolaでも前景に入る。局所背景補正だけでは、濃い汚れと筆画の区別は解決していない。 |
| [朱印と黒文字](200010454_00002_2/roi_02.png) | 黒文字と朱印の主要な線が前景に残るが、薄い朱印の線は取りこぼす場所がある。今回の方式は赤・黒を分けていない。 |

**学習なしで、少なくとも既知の筆画欠損を改善する候補が得られた。濃い汚れの混入や薄い線の取りこぼしは残る。** 全体精度や未知の冊への汎化を確認した結果ではない。

## 比較条件

| 方式 | 入力と処理 |
|---|---|
| v1 ACE CSC | 前回レビューの凍結v1出力を利用。黒文字・赤文字マスクの和を前景とする。 |
| v3 同じACE CSC | 前回レビューと同じCPU ACE・明度救済ありの出力を利用。黒＋赤の和。 |
| 原画像 Sauvola | 元画像を灰色化し、窓75、k=0.2、R=128で暗い前景を抽出。 |
| 局所背景補正＋Sauvola | 背景に対する輝度比で正規化した画像に、同じ窓75のSauvola。 |
| 局所背景補正＋3尺度多数決 | 同じ正規化画像に窓31・75・151のSauvola。2尺度以上で前景なら採用。 |

背景推定だけ、縦横およそ1/4に縮小した灰色画像で行う。31×31の楕円構造要素によるclosing、sigma=2のGaussian平滑化の後、背景推定を原寸へ戻す。背景推定値を元の灰色値以上にし、`clip(255 * gray / max(background, 1), 0, 255)`を分類入力とする。丸めてuint8化する。これらのパラメータは4ページ共通で、今回の目視結果に合わせてページ別調整はしていない。

分類とマスク保存は原解像度。分類用の灰色化・背景補正によって原RGBを書き換えない。プレビューは原RGBに青い候補領域を重ねたもの。合成や色の復元を行った結果ではない。

CSCは元の外周4%の強制背景設定を保ち、局所方式は強制背景を使わない。外周の違いをアルゴリズムそのものの改善と混同しない。全方式の青は「前景候補」であり、今回は朱墨・汚れの4クラス比較ではない。**前景の補集合を汚れや編集許可領域としては扱わない。**

3尺度の票数と不一致マスクも保存した。不一致は窓サイズへの依存を示す診断で、正解ラベルや校正された不確実性ではない。

## 後続の優先順位

1. 原画像Sauvolaを単純な比較基準として残す。局所背景補正・多尺度判定の追加価値を、薄い線と紙のムラで分けて確認する。
2. 元画像の色情報と筆画の形状を使う、学習なしの候補を追加する。濃い汚れを大きさや丸さだけで自動削除すると、実際の文字まで削る可能性があるため、曖昧な場所は保留できる設計を検討する。
3. 朱墨の候補を元RGBから別に調べる。単に「赤判定をしていない」ために赤誤検出がなくなったことを改善として数えない。
4. 候補が絞れた後、手動の評価用注釈で文字欠損・汚れ混入を測る。その後に固定した背景補完・DDRMで確認する。

## 再現・記録

```bash
/home/imoto/miniconda3/envs/diffusion/bin/python -B scripts/benchmark/compare_training_free_preprocessing.py
```

実装は[scripts/benchmark/compare_training_free_preprocessing.py](../../scripts/benchmark/compare_training_free_preprocessing.py)、ビューアのテンプレートは[training_free_viewer.html](../../scripts/benchmark/training_free_viewer.html)。全条件が同じパラメータを使い、各ページの6枚比較図と14 ROI比較図を出力する。既存の入力や凍結実装は変更しない。出力・描画キャッシュはプロジェクト内へ保存する。

[manifest.json](manifest.json)は元入力・参照マスク・実装のハッシュと環境・設定、[diagnostics.json](diagnostics.json)は前景面積とv1からの追加・除外画素数、[complete.json](complete.json)は計算出力のハッシュを記録する。面積率と差分画素数は精度・Recallではない。

画像のハッシュ、原RGBの一致、原寸・マスク極性、プレビューのマスク外が原画像と一致すること、ビューアの画像参照とJavaScript構文を検証した。[verification.json](verification.json)に結果を保存。ブラウザー実機での操作テストは実施していない。
