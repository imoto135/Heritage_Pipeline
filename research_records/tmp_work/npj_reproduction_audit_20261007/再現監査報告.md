# NPJ再現の監査と比較基準の見直し

2026年10月7日。対象は、2025年12月6日公開のNPJ論文と、手元の再現実装・保存結果・前回の接触シミ実験。

**現状の実装を「論文を十分に再現できた基準」とは確認できない。前回示した大きな黒い塊を、NPJ原法の失敗と断定するのは撤回する。** 過去のローカル再現も正解扱いせず、論文掲載結果との対応を別に検証する必要がある。

今回、3ページについて旧マスクを再生成し、8条件の全ページ推論を実施した。代表例の黒い塊は、重みだけを替えても残る一方、**既に存在する後年のv2マスクに替えると大きく減った**。再学習より先に、比較基準とマスク生成の妥当性を確かめることを勧める。

推論背景はToTensorの[0,1]、学習は[-1,1]。この整合性も未検証である。今回この規約を変更した実験は行っておらず、黒い塊の原因と断定しない。別スクリプトの二段階DDRMを足すことも、論文の二段階マスク生成の再現とは同義でない。

## 原因を分けた全ページ実験

いずれも原寸の全ページを推論し、PNGは同じ座標の切り出しを表示した。背景、パッチ128、重なり32、20ステップ、seed999を固定。変更する項目は重み、黒・赤マスク、入力RGBのいずれか一つ。マスク変更で乱数消費が変わり得るため、全時刻のノイズが一致した厳密な対照とは言わない。

| 例 | 条件変更 | 観察 |
|---|---|---|
| T01：hnsd007_023 | 重みだけchar／pageに変更 | 大きな黒い塊が残る |
| T01 | マスクだけ既存v2に変更 | 塊が大きく減る。細部の文字保持は未保証 |
| N01：200010454_00003_2 | 重みだけchar／pageに変更 | 円形の黒い塊が残る |
| N01 | マスクだけ既存v2に変更 | 円形の塊が大きく減る。細い線の途切れは残る |
| N02：200021071_00032_1 | マスクだけ既存v2に変更 | 茶色の貼り戻しと文字周辺の乱れが減る |
| N02 | 入力だけ保存ACEに変更 | 差分169,325画素は旧赤マスク内だけ。黒い復元は変わらない |

旧マスクは保存ACE入力から再生成し、**3ページ×4クラスの全画素が保存マスクと一致**した。少なくともこの3例は別入力の古いマスクを誤って取り違えたケースではない。ただし、ローカルv1を再現できたことは論文の再現成功を意味しない。

この実装は、固定マスクから背景への観測を構成しており、原画像RGBを黒文字の直接観測として使っていない。そのため入力をACEに替えるだけでは黒い塊が治らないことが、N02の実測とも整合する。

| 切り出し内の黒マスク画素 | v1 | v2 |
|---|---:|---:|
| T01：450×450 | 71,048 | 17,353 |
| N01：190×220 | 7,713 | 2,759 |
| N02：520×560 | 30,299 | 19,624 |

これは分類された面積であって、シミ除去精度ではない。真の文字・シミ注釈はない。v2による塊の減少は確認できるが、文字を完全に保持したことや別写本への一般化は未確認。

## 再学習と研究方針

**今回の黒い塊を減らすためだけなら、再学習は第一候補ではない。** 既存v2マスクで改善するため、旧v1を基準に新手法の貢献を主張すると、既に実装済みの改善を再発見してしまう。

原法に合わせた学習が必要かは、対応する重み・設定が回収できるかで変わる。回収できなければ、論文の条件に合わせた再学習が必要になる可能性が高い。ただし4,829ページの選び方・分割・ラベル・完全な学習条件が不明なままでは、新しい重みを作っても原実験の完全な再現にはならない。残っている重みの名前だけで原法と決めず、構造と来歴を確認する。

次の順序を提案する。

1. 掲載図のページ識別、元の切り出し、ACE・CSC・マスクの規約を確定する。原法との一致を確認できるコード・設定・重みがあれば採用する。
2. 同じ掲載例でマスクと復元の品質を照合する。回収不能なら、不明点を明示した論文準拠の再学習へ進む。
3. 認証できた基準と現在の既存v2を両方比較する。文字を読みづらくする失敗がそこにも残るページだけを研究対象に選ぶ。
4. 文字を消さない汚れ除去を、写本単位で分けた未知データで評価する。局所の文字保持注釈と読解評価を設け、画像がきれいに見えるだけの改善と区別する。

この監査では新たな学習は行っていない。再現の不確かさを解消する前に研究上の新規性や一般化を断定しない。前回の合成データ実験等はローカル条件の結果として残るが、NPJ原法への優位性の証明には使わない。
