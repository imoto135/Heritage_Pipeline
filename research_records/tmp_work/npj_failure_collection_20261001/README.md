# npjの失敗収集とv6の対策確認

第1回の比較を実施済み：[比較一覧](index.html)、[所見と結果](report.md)、[箇所別CSV](case_review.csv)。本文8ページ・7冊の問題8箇所＋対照3箇所。問題の暫定目視結果は改善4・部分改善3・未解決1。全資料の精度ではない。全6,072ページを縮小画像で走査し、候補58ページを一覧で確認、イラスト13ページと表紙1ページを除外した。新しい3ページへ条件固定v6を適用し、既知5ページは原画像一致・出力ハッシュを確認して再利用した。

`screening_scores.csv` は原画像による候補探索の値、`screening_review.csv` は対象範囲の目視記録、`baseline_review.json` はv6比較前に決めた箇所・旧npj所見、`v6_visual_review.json` は比較後の暫定判定。`page_inventory.csv` で確認済み・除外・未確認を区別している。未確認のページを失敗なしと数えない。

2026-10-01。ユーザーの方針：既存npjの失敗を集め、同じ位置を固定v6で比較して、何に対策できているか確認する。イラストを含むページは主評価から除外する。

基準の全量出力は `data/split_dataset_csc_mask/<split>/<book>/<page>/`。ACE済み画像は `data/split_dataset_csc/<split>/<book>/<page>.jpg`、元画像は `data/split_dataset/<split>/<book>/<page>.jpg`。旧版v1を基準とし、`split_dataset_csc_mask_v2` や枕草子のv3出力と混ぜない。過去の少数CPU再計算レビューと、既存全量出力も区別する。

6,072ページの入力・出力パスを `page_inventory.csv` に保存した。train 3,878、val 790、test 1,404ページ。画像の全量目視や精度評価は未実施。ページ一覧は失敗ラベルではない。

収集候補は、濃い汚れを墨として保護する例、薄い筆画や朱墨が劣化候補へ入る例、虫食い・穴・影を墨として拾う例。原画像と既存npj出力を見て位置と所見を記録し、v6を確認する。既存の比較で見つけた箇所も、全量出力の同じページで再確認してから失敗と扱う。黒・朱マスクは0が検出画素、劣化マスクは255が候補である。

失敗収集による評価は選定した問題への対策率であり、全資料の精度ではない。汚れを余分に残す副作用と、問題の少ない本文での悪化も別に確認する。改善が復元へ伝わるかは固定した復元器での比較で確認する。現段階ではしきい値変更・新手法実装・原画像変更は行っていない。
