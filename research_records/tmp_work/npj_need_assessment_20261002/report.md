# 保存npjに改善が必要か：論文の限界と実画像の照合

2026-10-02。新しい手法を実行せず、実際の保存npjとその入力だけを比較した。

**npj全体を置き換える必要性はまだ示せない。ただし、薄い主線の分断と、文字・枠線に接する濃い汚れは、改善対象として優先確認する価値がある。** 最近扱った数画素の接続補完より、大きな形の欠損候補を先に評価する。同時に、既存npjで既に除去できたシミを、新手法が必要な失敗として扱わない。

まず見る比較は次の3つ。

1. **[薄い主線の分断：原画像＋3保存版](24_saved_versions_faint.png)**。原画像の本文列に見える長い曲線・輪郭が、3つの保存版で点線状・断片状になっている。数画素の接続とは規模が異なる。目視では有望な失敗候補だが、必要な筆画と読解への影響は人の確認が残る。
2. **[文字・枠線に接する濃い塊](10_rule_crossing_dark_mass.png)**。保存入力の暗い範囲が、出力では文字・枠線とつながる黒い塊になっている。ただし、実推論入力は参照原画像よりかなり濃く、この保存設定の失敗である。原画像をそのまま使う通常設定でも同じ問題が起きるとは、今回だけで判断しない。
3. **[同じ斑点：旧切り出し版と全ページ版](26_stain_crop_vs_page.png)**。旧v1/selfrefでは茶色い塊と不自然な輪郭が残るが、CSC v2の全ページ保存版ではほぼ除去される。同じ斑点を両版の共通失敗とは数えない。推論範囲・参照背景なども異なり、マスクだけの効果ではない。

## 論文に書かれた限界は残るか

[npj論文のResults・Discussion](https://www.nature.com/articles/s40494-025-02214-8)では、裏写りの抑制不足、赤黒近接時のマスク曖昧さ、原画像にない虫食い風模様の生成、パッチ境界と色再現の変動を挙げている。以下は今回の保存画像への照合結果であり、論文での発生頻度を再現した評価ではない。

| 論文の課題／関連する課題 | 今回の保存画像での所見 | 改善の必要性についての判断 |
| --- | --- | --- |
| 裏写りの抑制不足 | [主線の横の灰色像](old_06_page_faint_middle.png)などは大きく減るが、黒い点・断片が残る。残ったものが裏写り・紙のノイズ・表の筆画のどれかは未確定 | 分離の評価候補。灰色像をすべて消すことも、すべて筆画として戻すことも正解としない |
| 赤黒近接時の誤分類 | [朱印と黒文字の重なり](07_red_seal_control.png)では、赤色と印影の全体は残る。細い線・小さい点には原画像との差が見える | 朱印が全面消失する例は今回確認していない。細部の保持は別途評価が必要 |
| 原画像にない虫食い風模様の生成 | 今回の全体縮小走査と拡大比較では、論文の報告に対応する明確な新規虫食い風模様を特定できなかった | 「解決済み」とはしない。元からある斑点の不自然な輪郭や実際の穴の誤分類とは区別する |
| パッチの継ぎ目・色再現の変動 | 背景は原画像より明るく平滑な参照紙面に置き換わる。枠線や文字には粗さがあるが、今回の走査で目立つ継ぎ目の位置を特定できなかった | 参照紙面への置換と意図しない変色を分ける。紙の質感の微調整を最優先にはしない |
| 薄い文字・筆画の保持 | [薄い主線](21_faint_column.png)と[別ページの下部の細線](22_lower_faint_column.png)には、目視で分断・欠損候補がある。濃い主線は多くの対照で明瞭 | 今回最も優先して確認すべき対象。数画素の補完だけでは十分に対処できない |
| 汚れを文字らしく強調すること | [接触する濃い塊](10_rule_crossing_dark_mass.png)が残り、[上余白の暖色の跡](23_upper_mark.png)は黒い断片へ変わる。余白の跡の材質は未確定 | 接触汚れは入力条件も確認して評価する。余白の小さい跡は、文字への影響がある失敗より後順位 |

論文は、実劣化の少数領域への注釈や専門家による確認、読解性を含む評価を今後の課題として挙げている。今回はその前段の目視整理で、筆画の正解データ・読解試験は作っていない。[Discussion](https://www.nature.com/articles/s40494-025-02214-8)

## どれくらい残るか：言える範囲

主比較は**既知5ページ・6保存フレーム**。同じ200010454ページの旧切り出しと全ページ版が含まれ、独立した6文書ではない。さらに同ページのv2fix／v3fix保存版を補助比較した。20既存ROI、全範囲を覆う53タイルの縮小走査、その後に選んだ3拡大を確認した。

薄い主線の分断候補は少なくとも2ページで確認した。黒い接触汚れの明瞭な候補は1つの保存cropで確認した。ただし、これらは選んだ開発例であり、**2/5などを全文書の失敗率にしない**。専門家が確認した文字欠損の件数でもない。以前の6,072ページの走査は、主に原画像と分類マスクであり、全文書の最終npj画像の失敗率ではなかった。

保存画像の所在を[CSV](saved_result_inventory.csv)へ整理した。`result/*.png`が1,190ファイルあるが、1,127は`results/otsu`の別方式。残りにも人工劣化試験、crop、複数版、他方式が混在する。**1,190枚のnpj最終出力があるという意味ではない。** この一覧は通常npjの出力認定でも、保存の不存在を証明する完全な全形式検索でもない。

実際の虫食い・裂けの誤分類は過去のマスク比較で見つかったが、今回の6フレームにはその失敗ページの最終復元画像を含めていない。虫食いの最終出力上の悪影響や発生頻度は未確認のまま。

## 入力・保存版を混ぜない

| 保存フレーム | 保存版・範囲 | 参照原画像と実入力 |
| --- | --- | --- |
| 200019865_00003_1 | ddrm_visual_check・全ページ | 全画素一致 |
| 200017197_00008_1 | trial_run・全ページ | 異なる。保存入力には参照にない斑点がある |
| 200010454_00002_2 | CSC v2・全ページ | 全画素一致 |
| hnsd001_011_crop | 旧v1・620px crop | 異なる。保存入力の濃淡が強い |
| 200010454_00002_2 | 旧v1/selfref・550×500 crop | 同位置の原画素と一致 |
| 200018243_00003_2 | v1trueという保存名・全ページ | 全画素一致 |

4フレームは参照と入力が一致し、2フレームは異なる。異なる場合は「参照原画像／実推論入力／保存npj」の3列表示にした。効果の判断は実入力と出力で行う。保存名から、論文の最終工程や利用者が覚えているnpj版と同一だと保証しない。今回の確認で過去の全実行ソース・合成・乱数を再現したわけではない。

## 次の研究対象

まず、[長い薄い主線](24_saved_versions_faint.png)と[別ページの細線](22_lower_faint_column.png)について、原画像上で保持すべき筆画を少数だけ確認する。同時に、接触汚れは濃淡の異なるcrop条件と通常入力条件を区別する。ここで、必要な線の損失や読解を妨げる汚れが確認できれば、改善の目的が明確になる。

その結果に応じて、筆画の欠損を作らない分類／復元と、接触汚れを編集する処理を別に比較する。現在のv6・DocRes試作がこれらを解決したという結論にはしていない。旧版だけに残る斑点や正常紙面の色調整は優先順位を下げる。
