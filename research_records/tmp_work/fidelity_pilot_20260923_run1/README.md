# 忠実度優先の技術試走

目的: 元の文字・紙色を保ってシミを除くための段階別比較。
実行: `scripts/benchmark/run_fidelity_pilot.py`。旧v15そのものではなく、新しい`fidelity_v1`レシピ。

## 条件

- 2ページ: 200017197_00070_1、200017197_00357_1。
- 合成シミ強度: 0.00、0.30、1.00（6入力）。0は未劣化対照。
- 同一の改良CSC、明度rescueオン。CSC seed 42、拡散seed 999。
- 紙色の固定・フラットフィールド・文字gain・残存シミの全域掃討なし。
- 128pxパッチ、overlap32、20steps、eta0.5。上流DDNMは1パス。
- 赤文字は全処理で同じCSCマスクに従って元入力から合成。

| 記号 | 出力 |
|---|---|
| X | 入力そのもの |
| P0 | 単純自己背景＋元入力の文字合成 |
| P1 | 劣化領域を膨張して補完＋元入力の文字合成 |
| R1 | P1を参照とする上流DDNM |
| F0 | 単純自己背景を参照とするDDRM |
| Fp | P1を直接参照とするDDRM |
| F1 | R1を参照とするDDRM |

6入力×上流1回＋下流3回＝24回のページ単位拡散処理。P0/P1は拡散なし。全体は2GPUで分担。

## 評価

シミ・文字候補・薄い文字候補・赤文字候補・背景候補のMAE/ΔE00、明暗変更量、RGB-PSNR、gray-SSIMを記録。
`dark150_proxy`は元画像と出力を同一閾値150で二値化した診断値で、人手による文字形状の正解ではない。

文字領域は自動proxy。正式な文字保存・可読性・汎化・統計的有意性の主張には使わない。LPIPSはこの技術試走では未実装。小領域の人手注釈と独立確認実験は後続作業。

`paired_differences.csv`は対象−対照の差。MAE/ΔE00は負が改善。シミ強度0のシミ領域指標は空欄（NA）。

## 記録と再開

- `status.json`: running/complete/failed。
- `run.log`: 進行ログ。各ページ/強度ディレクトリに段階別ログ。
- `manifest.json`: 入力・ソース・重みのハッシュと環境。
- `source_snapshot/`: 実行開始時の99個のPythonソース。
- 各段階の`stage.json`: 時間・VRAM等。
- 各ケースの`metrics.csv`と`review.png`: 評価値と事前固定座標の原寸切り出し。
- 成功段階は条件と出力ハッシュを検証して再利用可能。途中出力は存在だけで正常終了扱いせず、手動確認を求めて停止する。

重みの実際の学習画像一覧は未確認。保存ACE入力の由来にも制約があるため、この試走は開発用。既存結果を上書きしない。
