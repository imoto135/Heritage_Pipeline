# 07：直前ページの鏡像対応による除去候補の検証

2026-10-09。対象はtest由来の開発例`200021071_00033_2`、参照は`200021071_00033_1`。直前ページの左右反転像を位置合わせし、既存Howe候補から裏移りだけを除去できるか調べた。

**今回の厳しい条件では除去候補は0画素となり、黒文字マスクを変更しなかった。** 原画像に見える淡い文字状の像の大部分は既存Howe＋DDRMですでに消えている。一方、残る淡い短線・点には、直前ページの濃い本文で説明できないものがある。対応の不明な像を裏移りと断定して消す段階にはない。この陰性結果は「Howeに裏移りが一切残らない」「文字欠落がない」という意味ではなく、今回の参照と条件からは追加除去の根拠が得られなかったという意味である。

## 位置合わせの確認

参照の原画像・CSC黒マスクを左右反転し、対象の1968×3264画素へ寸法合わせした。文字のSIFT特徴では25対応中3点しか整合せず、縮退した変換となったため棄却した。最終的にはCSC候補内の小さく孤立した点を抽出し、20px以内の相互最近傍7組からRANSACでアフィン変換を推定した。画像IDに応じた手指定の座標は対応点の抽出に使っていない。

7組中6組が採用され、採用点の残差は約0.17〜1.24pxだった。採用点を1組ずつ除いて他の5組で推定する確認では、外した点の誤差が約0.23〜3.92pxとなった。対応点の切り出し画像でも紙面上の点の対応を確認した。文字付近の1組は残差22.28pxで除外した。

ただし、採用点はおおむねx=1052〜1728、y=132〜2205の右側に偏る。左側の位置精度、紙面の局所的な変形、各文字の対応精度をこの値で保証できない。紙面上の点の対応は幾何変換の根拠であり、それ自体を裏移りの正解ラベルには使わない。

## 除去条件と結果

元のHowe連結成分を単位とし、面積16画素以上、参照の濃い画素（グレー130未満）の5px近傍に70%以上対応すること、対象側にはグレー130未満の画素がないこと、保存CSC黒の占有率5%以下、赤候補との重なりがないことをすべて要求した。参照支持には、生の参照画像の濃淡を使用した。参照のCSCマスクにも薄い像や紙面上の点が含まれるため、その重なりだけで裏面本文とは判定しなかった。

全ページ・既定本文ROIともに選択0画素だった。完成した試作黒マスクは元のHoweと配列が完全一致し、赤マスクも完全一致する。従って新しいDDRM推論は行わず、既存のHowe出力をハッシュ確認付きで再利用した。画像は新手法の改善を示す比較ではなく、位置合わせと除去判断の検証である。

別途、面積8画素以上かつ対象の濃い画素率15%未満という広い診断条件で8成分を抽出した。その文脈比較では、本文の淡い短線が参照の濃い文字と対応しない例や、両ページに共通する淡い傷状の像も確認できる。これらは未注釈の確認候補であり、8成分すべてを裏移りや汚れと分類していない。

近隣`00032_2`、`00034_1`の鏡像も[一覧](neighbor_screen.jpg)で確認したが、これらへの局所位置合わせや成分ごとの対応判定は未実施である。直前ページ以外の寄与を排除したわけではない。

## 今後の扱い

Howeを筆画保持の候補として維持し、今回の対応条件は追加除去に採用しない。前回の「07に裏移り由来とみられる点・短線が残る」という記述は、残存像の由来が未確認という留保を付ける。CSCで消えるという理由だけで裏移りとは判定できず、CSCには原文字の欠落もある。

次の評価では、6例のうち07で残る像を「表文字」「対応が確認できる裏移り」「傷・点状像」「不明」に分け、判定不能を無理に除去対象へ入れない。同時に、選定・調整に未使用の別資料でHoweの筆画保持と前回の孤立点条件を検証する。6例は開発例として固定し、ここでさらに全体パラメータを合わせ込むことは優先しない。

位置合わせの診断と除去条件は[再現スクリプト](../register_bleed_pair.py)に保存した。既存推論の乱数はマスク変更により全段の画素別対応がずれる可能性があるが、今回はマスク完全一致と既存出力の再利用により比較出力自体の変更はない。
