# 6課題における文字マスク差し替え後のDDRM比較

2026-10-09。test由来の開発用6事例（01・02・03・04・06・07）について、原寸全ページのパッチDDRM出力をCSC v2・Sauvola・Howeの黒文字マスクで比較した。6事例×3条件、計18出力がそろった。[6課題の一覧PNG](6課題_DDRM_3文字マスク比較.png)。各課題は[01](01_DDRM_3文字マスク比較.png)・[02](02_DDRM_3文字マスク比較.png)・[03](03_DDRM_3文字マスク比較.png)・[04](04_DDRM_3文字マスク比較.png)・[06](06_DDRM_3文字マスク比較.png)・[07](07_DDRM_3文字マスク比較.png)で原寸ROIを確認できる。

## 考察

**文字を拾う強さはHoweが最も高い。** 特に01・02・03の薄い筆画でCSCの断片化が目立つのに対し、Howeは連続した字形を多く残す。Sauvolaは概ね両者の間にある。ただしHoweが拾う黒像には不要物も含まれ、07の裏移りではCSCの方が清潔な出力になる。したがって「文字保持」と「不要像の抑制」を分けて評価する。

| 課題 | 文字保持・有用な像 | 不要像・限界 |
| --- | --- | --- |
| 01 薄い筆画 | HoweとSauvolaはCSCで途切れる細い曲線の一部を連続して残す。Howeが最も多く拾う。 | 3条件とも淡い階調を強い黒線へ変える。原形保持や読解性は別途確認が必要。 |
| 02 広い染みと低コントラスト文字 | 右寄りの淡い文字はHoweが最もまとまり、Sauvolaが続く。CSCは複数箇所で欠ける。 | 選定時点で旧02より弱い代替事例。02と03は同じ資料で独立例とは数えない。 |
| 03 染みと筆画の接触 | 染み近くの薄い字形もHoweが最も保持する。CSCでは大きく断片化する。 | 染みの着色自体は3条件とも大きく抑えられるが、文字と染みの境界に残る小片の正体は正解注釈なしでは確定できない。 |
| 04 本文外の孤立斑点 | 下部の印字は3条件とも概ね保持する。 | 余白の孤立した3点は3条件すべてで黒く残る。黒文字マスクの全体パラメータ調整だけでは解決していない。 |
| 06 虫食い状の紙面損傷 | このROIは文字保持の評価対象ではない。 | CSCは左上の枝状像をほぼ消し、Sauvola・Howeは黒く残す。いずれも紙や失われた文字を復元したわけではない。原画像の淡い赤印状の像も3条件とも消える。 |
| 07 裏移りと表文字 | Howeは表文字を比較的よく残し、Sauvolaより黒い断片が少ない。 | CSCが最も余計な黒点・断片を抑える。Sauvolaは裏移り由来とみられる点・短線が多く、Howeにも一部残る。 |

Howeを今後の**筆画保持を優先する候補**とし、CSC v2を清潔さの基準、Sauvolaを比較対象として残す。6例の印象だけで単一の最良法とは決めない。現在の6例でHoweのパラメータをさらに合わせ込むと、裏移りや斑点への過適合になり得る。

## 次に検討すること

2026-10-09追記：[07の鏡像位置合わせによる確認](../bleed_pair_registration/検討結果.md)では、残存候補の一部が直前ページの濃い本文に対応しなかった。上表の「裏移り由来とみられる点・短線」は未確定の目視解釈であり、裏移り正解として確定しない。今回の厳しい除去条件は0画素で、Howeマスクを維持した。

1. 6例では表文字、裏移り、染み、孤立点、紙損傷を分けて小範囲に注釈し、文字の欠落数・筆画の連続性と不要像の残存数を別々に記録する。最終的な性能比較には、今回の選定・パラメータ探索に使っていない別資料を確保する。
2. Howeを基本の黒文字候補とし、07の裏移りと04の孤立点を**局所的に**抑える方法を検討する。07は既に確認した前後ページの鏡像対応を手掛かりにできる。CSC黒との単純な共通部分はHoweが救った淡い筆画まで消すため避ける。
3. 06のような紙面損傷は文字二値化とは別タスクとして扱う。左上の枝状像を消すことを「虫食い修復の成功」とは判定しない。
4. 赤文字・赤印を別に検証する。今回の6ページは保存CSC v2赤マスクが**すべて0画素**で、06の淡い赤印状の像は合成で守られなかった。ただし、後の隣接ページ確認では直前ページの朱印の鏡像と形が対応し、裏移りの可能性がある。この消失を表側朱印の保持失敗とは確定しない。[隣接ページ比較](../red_retention_validation/R04_薄い赤像と直前ページ朱印.png)。表側の朱印が明瞭な資料を別に評価する。

## 比較条件と範囲

原画像、保存CSC v2赤マスク、DDRMの凍結コード・epoch350重み・伊勢物語背景、seed999、20段、128pxパッチ、重なり32、共有初期ノイズ、原寸処理を固定した。Sauvolaは窓61・k=0.20、Howeはc=160・高エッジ閾値比0.40。全18出力について、ファイルの存在、原寸サイズ、ログ内エラーなしを確認した。出力ハッシュと各入力のハッシュは[protocol.json](protocol.json)と[complete.json](complete.json)に保存した。

現行のDDRMが直接読む分類マスクは黒文字と赤文字のみで、CSCの背景・劣化マスクはこの推論では使われていない。従って今回の結果は「CSCの赤を固定して黒文字マスクを差し替えた比較」であり、CSCの他の3クラスをすべて利用したハイブリッド法の評価ではない。共有初期ノイズを使ったが、拡散過程の全乱数呼び出しの一致までは保証していない。目視比較は開発事例に限られ、未知資料での定量性能を示さない。

追加検討：[Howeの筆画を保ちながら孤立点を減らす試作](../howe_csc_fusion/検討結果.md)。04の3点は除去でき、印字出力は元Howeと画素一致した。CSC劣化の一律除去は淡い筆画を削るため棄却し、07本文の裏移りは別途検討する。
