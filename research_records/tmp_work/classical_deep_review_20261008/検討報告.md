# 黒文字抽出の古典手法を追加検討

今回の追加候補では、**Howe系の基本エネルギーが最も追う価値のある候補**だった。T01の大きな染みを抑え、N01・N05ではWolfで切れる細い筆画をより連続して残した。一方、N01の染み内の暗い点は残る。汚れ除去と筆画保存の両方で、一律にWolfやSauvolaを上回ったとは判断しない。

今回のHoweは著者の公開コードに基づく基本エネルギーのローカル移植で、著者実装の完全再現ではない。Cannyの実装差と自動パラメータ調整の未実施を残している。以下の性能所見は、この比較実装の結果を指す。

## 主比較

各画像は原画像・Sauvola・Wolf・Howe基本エネルギーの4枚。T01は大きな染み全体を含む600×600画素、N05は複数の文字を含む640×580画素、N01は染みと細線の190×220画素を整数2倍で表示した。

## 手法ごとの狙いと結果

| 系統・手法 | 仕組みと検討理由 | 今回の結果・判断 |
| --- | --- | --- |
| Howe基本エネルギー | ラプラシアンを分類コストにし、隣接画素の不整合コストと合わせてグラフカットで最小化する。ゆっくり変化する背景と細い暗い筆画を分け、画素ごとの閾値だけでは途切れる線を保つ方向。 | T01では染みを拾わず本文を残す。N01の上部曲線とN05の薄い筆画に改善が見える。暗く鋭い斑点も筆画として残す。追加候補の優先度は高いが、原実装照合と独立画像での確認が必要。 |
| Bradley–Roth | 局所平均より一定割合暗い画素を文字とする。平均だけで明るさに追従する単純な対照。 | 窓61・15%はSauvolaに近い。画像幅の約1/8の窓ではT01の染み付近の不要物が増えた。15%から10%へ緩めると細線と紙面ノイズがともに増える。 |
| Phansalkar | Sauvolaの閾値に、局所平均が低い場所で強くなる指数項を足す。低コントラスト向けの補正が染み上の筆画に効くかを確認。 | 窓61では大きな染みを落とすが、T01でWolfを上回る明確な筆画改善は見えない。N05の一部細線はWolfより残るが、Sauvolaより全面的に良いとは言えない。 |
| 背景推定→大津 | グレーのclosingで細い暗部を埋めて紙面背景を推定し、原画像をその背景で割る。その後に全体閾値を設定。染みの明るさを文字から分離する狙い。 | T01では染みを抑えるが、薄い筆画の確認点を落とす。N05も細線が薄くなる。推定サイズ31・61・121でも、今回の52点ではいずれも47点保持にとどまった。単純な大津への置き換えは優先しない。 |
| 背景推定→Wolf／Sauvola／NICK | 前処理の効果と閾値方式の効果を分ける対照。背景推定61に固定し、後段を変える。 | 背景補正→WolfではN01の曲線の切れ目が残る。背景補正→Sauvolaは筆画を保つが、確認点の数は原画像Sauvolaと同じ。背景補正だけで細線保存が改善するとは言えない。 |
| NICK | 平均と二乗平均を使う局所閾値。前回の細線保持候補を広い範囲でも確認。 | N01・N05の細線をつなぐが、T01やN01で小さな不要物が増える。文字候補を多く残す方向の対照として有用。 |
| Gatos／Suの前回再実装 | 背景補間と適応コントラストという別の設計を、今回の広い範囲で再確認。 | 前回の実装制限が残る。Gatosは原寸M=1、Suは自動筆画幅推定に課題があり、どちらも原法の性能を順位づけする根拠には使わない。 |

背景補正はGatosや2018年の背景推定・エネルギー最小化法の再現ではなく、closing＋除算という独立した比較条件である。

## 細線の連続性を別に確認

N01の細い曲線上に以前から置いていた、原画像で監査済みの10点について、出力マスクの8近傍連結を確認した。

| 方法 | 10点の保持 | その10点が属する文字候補の連結成分数 |
| --- | ---: | ---: |
| Wolf | 10/10 | 3 |
| Sauvola | 10/10 | 1 |
| NICK | 10/10 | 1 |
| Bradley61 | 10/10 | 1 |
| Phansalkar61 | 10/10 | 1 |
| 背景補正61→Wolf | 10/10 | 3 |
| Howe基本エネルギー c=80／160／320 | 各10/10 | 各1 |

つまり確認点を全て残しても、その間の線が切れていることがある。点の保持数だけではWolfの切れ目を評価できない。同じ曲線はSauvolaもつながるため、Howeだけの利点とも言わない。この診断は既存点を使った事後の探索であり、全筆画の正解中心線評価ではない。結果は `continuity_diagnostic.json`。

## 限定した計数

既存の原画像からの暫定点を監査した52点と、選択した非文字小領域13,000画素を再利用した。

| 条件 | 筆画中心の候補数 | 選択した非文字領域の黒候補数 |
| --- | ---: | ---: |
| Wolf61 k=.5 | 48/52 | 0 |
| Sauvola61 k=.2 | 49/52 | 0 |
| NICK61 k=-.1 | 50/52 | 56 |
| Bradley61 t=15% | 49/52 | 1 |
| Bradley 幅の約1/8 t=15% | 50/52 | 135 |
| Bradley61 t=10% | 50/52 | 56 |
| Phansalkar61 | 49/52 | 0 |
| 背景補正61→大津 | 47/52 | 0 |
| 背景補正61→Wolf | 47/52 | 0 |
| 背景補正61→Sauvola | 49/52 | 0 |
| Howe基本エネルギー c=80／160／320 | 各50/52 | 各0 |

これは画素精度、precision、F1、OCR正解率ではない。N01の暗い斑点のように、選択小領域の外にある不要物はこの表に含まれない。52点は細線全体を表す正解マスクでもない。Gatos再実装も50/52・非文字小領域0なので、この数字だけでは太りや欠落を含む目視の得失を表せない。

## 条件と実装の確認

同じ原画像の全ページをOpenCV RGB→グレーの0〜1へ変換して処理した。ACE、朱文字、DDRMは入れていない。既存のWolf・Sauvola・NICK・Gatos・Suは保存全ページマスクを使用し、入力条件を変えていない。

追加条件は新しい出力を見る前に `protocol.json` へ保存した。主に窓61を用い、Bradleyは窓幅と暗さの割合、Phansalkarは窓31、背景推定は31・61・121、Howeはc=80・160・320を別に保存した。3ページ×20条件のうち6条件は前回出力の再利用。比較画像30枚、各4パネル。

Howeの分類エネルギー、背景高信頼画素へのバイアス、Cannyを使った隣接コストの切断、末端の後処理は著者のIJDAR公開コードに沿って移植した。最小化には著者コードが指定するBoykov–Kolmogorov maxflow v3.01を使用した。MATLABがないため、`canny_old` はskimage Cannyと最大Sobel勾配による正規化で代替した。著者の自動パラメータ調整は実行していない。c=160・sigmaE=.6・tlo=.1・thi=.4は公開基本コードの既定値に基づくが、Cannyの数値的な同一性は保証しない。

グラフカットのラベル極性とエネルギーは、小さな2×3・3×3画像の全64／512ラベルを列挙した最小値と照合した。Phansalkar式と局所統計は直接小窓計算で照合。平坦な明るい紙の確認も実施した。保存PNG30枚の120パネルを元画像・全ページマスクと再照合し、60組の点・非文字領域計数を保存マスクから数え直した。元入力・前回マスクのハッシュは不変。`final_verification.json` に結果を保存。

既存パイプラインやデータは変更していない。今回の研究用コードとライブラリはこの比較フォルダに保存した。

## 次の優先順位

WolfとSauvolaを基準に残し、Howe系を追加候補として検証する。大きな染みのT01だけでは3方法の差が小さいので、薄い筆画を含む別資料で、筆画の連続性・太り・暗い斑点の残存を合わせて確認するのが重要。Howeの原法について結論を出す前に、著者のCannyと自動調整を含む実装との照合が必要。

背景補正→大津、Phansalkar、Bradleyは、今回の3例でWolf／Sauvolaから全面的に置き換える根拠が弱い。NICKは細線保持側の対照として残す。
