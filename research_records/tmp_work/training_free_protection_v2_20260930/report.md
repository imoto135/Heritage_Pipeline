# 学習なし：朱判定の改良と文字保護・編集許可の独立出力

2026-09-30。前版の色・形状処理を入力に、新しい試作を実装し、既知の12ページ・固定38 ROIと誤候補等の追加拡大領域で実行した。今回は12ページを改良に使っているため、開発・回帰確認であり独立した精度評価ではない。学習、事前学習モデル、手動正解ラベルは使っていない。

[比較ビューア](index.html)で原画像、前版の朱候補、改良した朱候補、文字保護・編集許可・保留を同じ位置で確認できる。候補の色は正解ラベルではない。画素の削除や復元は行っていない。

## 結果

- 前回追加した8ページの朱候補は、合計152,779画素から0になった。紙面内の墨の茶色い縁や斑点、撮影背景のノイズ、紙の縁の誤候補も拡大図で再確認した。この標本では明瞭な朱書きの陽性例を確認できておらず、候補数の低減は正解に対する誤検出率ではない。
- 既知の朱印ROIでは、前版の赤候補20,027画素すべてが文字保護に含まれ、編集許可から除外された。うち19,555画素を朱候補として確認し、残り472画素は色未確定として保護した。前版のマスクを保持した割合であり、朱のGT Recallではない。原画像にあるが前版でも拾っていない線は、この数値に含まれない。[朱印の比較](200010454_00002_2/roi_02.png)
- 同ページ全体では朱候補21,919→20,609画素、前版赤候補のうち保護された範囲は21,808画素。残る111画素は保留となり編集を許可しない。色ラベルを落としたことと、画素を編集してよいことを分けた。
- 既知の濃い楕円斑点3,131画素は、文字保護から分かれたまま編集許可候補に残った。[斑点の比較](hnsd001_011/blob_01.png)。この既知1例に基づく形状判断を、他の塊への一般的な有効性と同一視しない。
- 薄い筆画の拡大では、局所前景を維持し、複数尺度で拾われた近傍2画素以内も保護候補に追加した。文字近傍3画素以内の汚れ候補は編集許可から外した。[薄い筆画](200017197_00008_0/roi_01.png)、[墨の境界](200021869_00010_2/roi_03.png)。原画像の薄い筆画を全て回収したとは言えない。

## 朱判定で変えたこと

3×3のRGB中央値フィルタを、赤の起点を確認する入力だけに使う。保存・表示・合成用の原画像は変更しない。起点にはLabのa成分、黄方向との比率、HSVの色相・彩度、明度の条件を使い、前版の赤候補成分内に3画素以上の整合した起点を要求する。成分の原画像上の明度中央値が25未満なら、朱と確定しない。条件は全12ページで共通。[実行条件](manifest.json)

中央値フィルタ等で起点を確認しただけでは、200021851の暗い撮影背景に862画素の赤候補が残った。成分の明度条件を加えると0になった。両段階を `seed_supported_red.png` と `red.png` に保存し、ノイズ抑制と暗い成分の判定の寄与を区別した。

起点のない小さな赤成分でも、確認済みの朱候補から24画素以内で、成分明度中央値が25以上なら、色未確定の保護候補へ回す。朱印の細線・離れた断片を色の確定条件だけで落とすことを避ける設計である。新しい根拠を持つ朱候補を探索する方式ではなく、前版の赤候補を再評価する方式である。

## 独立したマスクの意味

| ファイル | 内容 |
|---|---|
| `protect.png` | 文字・枠線・挿絵等として残すインク候補。色未確定を含む |
| `red.png` | 今回の色条件で確認した朱候補。必ず保護に含まれる |
| `ink_color_uncertain.png` | 保護するが色を確定しない候補 |
| `stain_candidate.png` | 色・前版の塊判定による汚れ候補。保護・保留と重なり得る |
| `hold.png` | 編集を保留する範囲。色未確定のため保護と重なることもある |
| `edit_allowed.png` | 汚れ候補のうち保護近傍・保留を除いた編集許可の試作 |
| `protection_guard.png` | 保護領域とその近傍3画素 |

全二値マスクは255が該当、0がそれ以外。墨候補・朱候補・色未確定インク候補の和が保護領域に一致する。一方、汚れ候補・保護・保留は相互排他的にしない。編集許可だけが保護・保留と重ならない。

下流へ接続する場合は、編集許可のない画素を原画像から保持する契約が必要になる。今回はこの接続を実装していない。`protect.png` の補集合をそのまま編集領域にしない。画素GTで確認していないため、ファイル名の「許可」は規則上の判断であり、非文字汚れの正解を保証するものではない。

## 残る問題

- 墨と接触した茶色の斑点は、朱ではなくなってもインク根拠があるため保護・保留に残る。[枠線に重なる斑点](200021063_00021_1/red_audit_02.png)。朱誤分類の低減は、汚れ除去ができたことではない。
- 撮影背景は局所前景の時点でインク候補として拾われるため、朱候補を減らしても保護に残る。[撮影背景](200021851_00019_2/red_audit_01.png)。紙面外を識別する処理は未実装。
- 保護の拡張や編集保留により文字を残しやすくなる一方、近傍汚れも残しやすくなる。全ページの候補面積・保留・汚れ候補との重なりを[診断集計](diagnostics.json)に保存した。何も編集しない方法を優位にする評価にはしない。後で文字誤編集と汚れの編集対象率を併せて採点する。
- 暗い朱・退色した朱・紙色の異なる未見資料での性能は未確認。3×3、2・3・24画素等には解像度・筆幅依存がある。この12ページで条件を開発したため、別冊・別ページへの固定条件確認が必要。
- 裏写り、文字と汚れの重なり、既存局所前景の取りこぼしは未解決。候補面積や前版マスクとの一致をPrecision・Recall・F1として報告しない。
