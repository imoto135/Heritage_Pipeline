# インク・背景分解：断面での成立確認 v0

3ページ・5矩形は既知の開発資料。ニューラル学習・教師注釈・復元・新しい密な編集マスクは実施していない。

各ページの確定朱とrobust seedから自動抽出した断面を使い、対象矩形と40px周囲を除いて色方向を推定した。64pxタイルで推定用と確認用を分ける。各断面の画素値も4分割し、当てはめに使わない値で再構成誤差を計算する。断面位置・方向の決定は原画像全体を利用するため、この誤差は独立データの精度ではない。

色の表現3種類、背景5種類、インク幅6種類と背景のみを比較する。折り目対照では、追加の色付き線状背景も許容する。色付き折り目とインクを同時に分けるモデルは未実装。複数説明の寄与範囲は検討した有限候補の感度診断であり、厳密な上下限や校正済み確率ではない。
