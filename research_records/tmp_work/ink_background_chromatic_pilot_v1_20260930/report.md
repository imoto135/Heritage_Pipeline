# 共通の明暗成分を除いた色差の成立確認 v1

v0と同じ3ページ・5矩形・自動断面・色材推定を使用。背景や受理条件を緩めず、再構成の対象をRGB3成分から色差2成分へ変更した。対数色の共通の明暗成分は差で消える。RGB差は比較用で同じ不変性はない。

これは色差の再構成であり、原RGB・墨・紙の模様を完全に復元した結果ではない。雑音の共分散は近似で、CV値は校正済み確率ではない。色付き折り目は朱と同じ色差を作ることがある。

| 矩形 | 同じ自動断面数 | 通常背景：必要／曖昧／小／説明不足 | 色付き折り目許容：同順 |
|---|---:|---|---|
| near_seal_brown | 52 | 17 / 7 / 2 / 26 | 10 / 14 / 3 / 25 |
| remote_brown | 160 | 17 / 6 / 2 / 135 | 12 / 12 / 4 / 132 |
| faint_stamp | 160 | 3 / 0 / 0 / 157 | 3 / 0 / 0 / 157 |
| long_tail | 160 | 0 / 0 / 0 / 160 | 0 / 0 / 0 / 160 |
| upper_writing | 160 | 0 / 0 / 0 / 160 | 0 / 0 / 0 / 160 |

件数はGT精度ではない。赤褐色筆記ページの種不足はそのまま推定不能として残す。新しい密な編集マスク・ニューラル学習・手動画素GT・別冊への方法適用は行っていない。
