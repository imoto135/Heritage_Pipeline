# 別冊の赤色筆記・朱印：固定条件の比較

明瞭な朱線・細い印影を別冊でも保護できる例がある。一方、薄い朱印と赤褐色筆記の一部が編集許可に入る失敗を確認した。現方式を自動編集へ渡す段階ではなく、原論文やローカルv1への総合的な優越はまだ主張できない。

8冊・9ページ・14か所へ条件を変更せず適用した。学習・手動画素GT・拡散推論・削除／復元は行っていない。比較はローカル凍結npj v1（ACEなし／CPU ACEあり）、局所背景補正Sauvola、前版の色・形、改良版の独立した保護・汚れ候補・保留・編集許可で行った。

## 固定条件と計算の確認

原画像と14矩形は方法適用前の収集記録から引き継いだ。直近の調整用12ページの冊とは非重複だが、色で目的抽出した陽性資料であり、無作為な代表標本ではない。9ページのうち2ページは同じ冊 `200020019` で、冊数は8。暗い朱の十分な網羅もまだない。

局所Sauvolaは既存の入力準備関数をそのまま呼び、保存済みの既知1ページと局所前景・3尺度投票・正規化画像が一致した。色・形処理はハッシュを確認した既存スクリプトを変更せず使用した。改良版は凍結スクリプトのASTから計算部分を抽出し、ファイル読込だけを引数へ置き換えた。既知12ページ・各17マスク（計204）の画素一致を確認した。抽出コードと一致記録を保存している。

CPU ACEはalpha=5、200参照点、seed=0。CSCはseed=42、最大50,000標本、外周4%を強制背景とする以前の条件。CSCは各入力のPCA/GMMを推定する既存比較方式であり、教師データやニューラルモデルの学習は行っていない。原論文の完全再現が成立したとは主張しない。

## 原寸画像の所見

- **100249376_00056_1**：主要な矩形印影は確定朱と保護に残る。薄い下枠などに編集許可の黄が一部重なり、印影全体の保護が成立したとは言えない。

- **100249537_00003_2**：上下の赤い囲み線は前版と改良版の朱候補に残り、交差する墨も保護に入る。ローカルv1はACEなしで墨書の多くを劣化候補へ回し、ACEありで黒文字に戻るが紙面の黄候補も増える。

- **200006663_00002_2**：挿絵と交差する細く欠けた印影は、前版と改良版の朱候補に残る。挿絵も保護に入る。欠けた印影の全画素を保存できたという定量評価ではない。

- **200020019_00002_2**：明瞭な上部・下部の矩形印影は改良後も朱候補に残り、墨との重なりは保護される。v1のACEなしでは朱の濃い横線が黒文字にも分かれ、ACEありでは朱候補が増える。

- **200020019_00082_2**：薄い印影・明瞭な印影とも主な図形は確定朱と保護に残る。薄い印影では周縁や内部の点状に編集許可が残るため、全面的な保護成功とはしない。

- **200021086_00032_2**：低コントラストの印影では、前版が拾う部分の一部が確定朱から保留へ移る。前版も見落としている淡い部分に編集許可が重なる。ローカルv1のACEなしは周囲の紙も赤候補に含み、ACEありでは紙の劣化候補が増える。印影の見落としと紙の誤保護の両方を確認すべき例。

- **200021763_00002_2**：赤褐色筆記の濃い部分は確定朱に残るが、薄い文字・長い払いは色判定と局所前景の両方で欠ける。下の文字の広い部分に編集許可が重なる明確な失敗がある。前版朱が全て編集対象外でも、元画像の朱が全て守られるわけではない。 このページではv1のACEありの朱候補は0で、筆記の多くが黒文字候補となる。ただし長い払いはv1のACEありのほうが広く拾う箇所があり、改良版の保護が一方的に優れる結果ではない。v1は周囲の紙面にも劣化候補が広く出る。

- **200025191_00004_2**：明るい朱の細い枠と字形は前版・改良版とも候補に残り、墨との接触も保護される。候補の輪郭が原画像より太くなる箇所があり、画素精度を確認した結果ではない。

- **100249371_00002_1**：赤色の図形・文字は確定朱に残り、青い罫線や墨との交差も保護される。前版では墨の一部に赤候補が混じり、改良で減る例がある。青罫線は朱以外の保護対象として残るが、現状の分類名だけで墨と区別できるとは言えない。

## 失敗箇所の拡大と次の方針

[赤褐色筆記の下部](early_inspection/200021763_00002_2_lower_handwriting_detail.png)・[上部](early_inspection/200021763_00002_2_upper_handwriting_detail.png)・[薄い印影](early_inspection/200021086_00032_2_faint_stamp_detail.png)の拡大図で、同じ原RGBに保護・保留・編集許可を重ねた。これは固定14矩形内の拡大位置の指定で、追加の画素正解ラベルではない。

`failure_zoom_diagnostics.json` では拡大領域の編集許可が全て既存の `brown_field` に由来し、前版朱候補との交差は0だと確認した。弱い赤の色条件に入っても連結成分の種支持がなく前版朱にならない画素と、弱い色条件にも入らない画素の両方がある。したがって確定朱のしきい値だけを変えても、前版の候補域そのものの見落としは解消しない。これらの数は領域内のマスクの交差であり、真の朱画素数ではない。

次の改良では、確定朱の厳しい条件を維持しつつ、原画像の局所的な紙色との差・筆画のつながりから薄い赤褐色の候補を別に拾い、保護または保留へ回す。弱い赤条件そのものから漏れる筆画も対象にする。単に編集対象を減らしただけで改善としないため、既知の茶色い汚れ・墨の縁・撮影背景・赤がない8ページも回帰確認する。この9ページを調整に使う場合は開発資料へ移し、別冊の最終確認用資料を残す。今回は比較までで、固定条件は変更していない。
