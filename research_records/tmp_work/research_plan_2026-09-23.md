## 2. 研究の問いと成立条件

Q1: 単純自己参照に対して、背景精緻化がシミ誤差を減らすか。
- 同一CSC・同一下流DDRM・同一入出力仕様で比較する。
- 外部参照との差だけでは精緻化の追加価値を主張しない。

Q2: CSC改良は、誤って消える文字を減らし、シミの文字化を増やさないか。
- 元方式との全体差と、HSV・クラスタ構成・膨張・rescueの個別効果を区別する。
- 診断ROIでのマスク改善と、復元出力の文字保存改善を両方示す。

Q3a: 同じ精緻化参照に下流DDRMを加える価値があるか。
Q3b: 参照を作る上流DDNM自体に、古典処理に対する追加価値があるか。
- 前の「拡散処理の意味」はこの2問に分解する。
- DDNMを最終復元器として比較する実験は補助。一方、v15内部のDDNMは手法構成要素なので、コスト・効果の説明を省略しない。

成功条件は「主対照よりシミ除去が改善し、文字損傷と非シミ領域の変更が事前許容範囲内」で、画像全体の単一スコアの最大化にはしない。効果量・許容誤差は開発用注釈のばらつきと実用上の意味から設定し、確認セットを見る前に固定する。数値を結果に合わせて決めない。根拠ある許容幅を決められなければ、文字保存の非劣性は主張しない。

## 3. 比較条件の再設計

記号: X=劣化入力、M=CSCマスク群、B0=文字・劣化を補完した単純な自己背景、P=拡散を使わない背景補完と文字合成、D=上流DDNM、F=下流DDRM。

元v15はフラットフィールド補正・残存シミ処理・文字再合成・拡散を含む。現行の--enhanceを外すと残存シミ処理も外れるため、単にtext_gainやbg_targetを変更しただけでは要因分離にならない。これらを独立設定に分け、変更版を元v15と区別する。bg_target<=0も照明を平坦化するので「原本の紙質保存」を保証しない。

### 最小の段階別比較（まず改良CSCを固定）

| 条件 | 出力 | 何が分かるか |
|---|---|---|
| X | 無処理入力 | 改善の起点 |
| P0 | B0に入力の黒・赤文字を同じ規則で合成 | 単純自己参照の古典処理対照 |
| P1 | v15と同じ前処理・文字合成、上流拡散なし | 古典処理部分の効果 |
| R1 | P1に上流DDNMを1回適用した参照 | 上流拡散の追加価値 |
| F0 | DDRM(X, M, B0) | 単純自己参照のDDRM |
| F1 | DDRM(X, M, R1) | 精緻化＋DDRM |
| Fe | DDRM(X, M, 外部参照) | 既存方式との関係を示す補助対照 |

P1、R1、F1で文字・朱書の最終合成処理を可能な限り揃え、生の段階出力も保存する。単純なB0は文字を消した画像なので、そのまま全文字復元結果として採点しない。P0の合成は評価GTでなく入力と推論マスクだけを用いる。

主要な対応比較はF1対F0、F1対R1、R1対P1。加えてF1対P1で処理全体の追加価値を確認する。

2パス目は最初から標準にしない。1パスで価値が確認されたら、同じ前処理を2回行う古典対照と比較し、単なる処理反復・文字濃色化・演算量増加から分離する。パス数、各段階の入力、マスク再推定の有無を明示する。

### CSC比較と介入

- 最小の2×2: 基準CSC／改良CSC × 単純自己参照／精緻化参照。下流復元器はDDRM固定。
- 基準CSCは、論文相当のv1と、開発中のv2 rescueなしを混同しない。v1は既存方式との比較、v2→v3はrescue機構の検証に使う。
- 背景生成だけに新CSCを使う条件、下流の黒文字ガイダンスだけを交換する条件を診断ROIで実施。赤字の最終合成は別に固定・交換する。
- GTシミマスクを与えるoracleは診断専用であり、実用成績に混ぜない。
- HSV・クラスタ構成・形態処理・black_dilate_r・明度rescueは機構ごとのアブレーション。全組合せを全ページで回す必要はないが、都合のよい例だけで結論しない。

## 4. データとGT

### 探索用

既存枕草子20ページ×4強度を利用する。過去に選定・評価・調整に使用したので確認用テストと呼ばない。2ページの試走は入出力と失敗診断専用で、効果の統計判断には用いない。

### 確認用

- 未使用ページ・未使用の冊を、方法の結果を見る前に選定。まず2〜3冊から各10〜20ページ程度を候補にするが、これは作業量の目安で統計的十分性の保証ではない。
- 枚数よりも、紙色・文字密度・薄い文字・朱書・シミ形状を含むことを重視。必要標本数は開発データのページ間変動と検出したい差から見積もる。
- 同一見開き、隣接ページ、同一原画像のクロップを開発・確認に分散させない。識別子だけでなく画像重複も確認する。
- checkpointの実際の学習履歴を照合する。現行trainリストに枕草子IDがないだけでは、既存重みの非混入を証明できない。保存コードは学習ファイル一覧をcheckpointに含めていない。確認不能なら限界として明記する。

### 劣化条件

1. 強度0: 合成シミなし。余計な文字変更・背景変更を測る必須の対照。
2. 従来の文字回避シミ: 過去結果との連続性と無傷文字の保護を測る。
3. 文字に重なる半透明シミ: 「重なった文字を救う」と主張する場合に必須。単なる完全塗り潰しは情報欠落を伴う別条件とする。
4. 実劣化: GTを作れないので、手動確認ROIと読解評価で補う。自然劣化の全面復元の正確性は断定しない。

同一ページ・同一シミ形状を強度間で共有する。独立したシミ形状seedも開発段階で複数検証する。強度と色・面積を同時に変えない。旧生成法を改変するときは別バージョンとして保存する。

元画像は「合成前画像」であって、物理的に劣化のない原本ではない。天然のシミまで消した場合にGT誤差が増えることを解釈に含める。

### 注釈

黒文字の芯・薄い線・赤文字・シミ・確実な背景・曖昧領域を含むROIを出力閲覧前に選ぶ。可能なら2人で一部を独立注釈し、不一致を記録する。曖昧境界はignore領域とし、範囲を開示する。採点ROIは入力/元画像から固定し、手法ごとの出力で選び直さない。

## 5. 評価指標

GTをI、出力をO、付与シミをS、固定黒文字領域をT、赤文字をR、確実な非シミ背景をBとする。重なりシミではS∩TとS\Tを分ける。領域は手法出力に依存させない。

| 目的 | 主な指標 | 解釈と注意 |
|---|---|---|
| シミ除去 | S内の輝度MAE、S内のΔE00 | 小さいほど元画像に近い。輝度誤差を主評価、色差を必須の補完とする |
| 文字の濃度保存 | T内MAE、明るくした誤差と暗くした誤差を分離 | 平均誤差だけで線の保存を断定しない |
| 文字形状保存 | 注釈ROIの文字precision/recall/F1、細線・輪郭の欠損と偽線の確認 | 二値化・境界許容幅は共通の固定手順。推論CSCを採点器にしない |
| 非シミ背景の保全 | B内MAEとΔE00 | 背景全面置換・過剰平坦化の副作用を検出 |
| 赤文字保存 | R内ΔE00と形状precision/recall | 黒文字平均に埋めない |
| 既存論文との比較 | 全体RGB-PSNR、gray-SSIM、LPIPS | 補助指標。良い値だけで文字が正しいとは言えない |
| 実用性 | 全工程時間、各段階時間、ピークVRAM、失敗件数 | 参照生成・CSC・I/Oを含む。品質とコストを併記 |

MAE_A = mean_{p∈A}|gray(O_p)-gray(I_p)|。Tの明るさ増分=max(gray(O)-gray(I),0)、暗さ増分は逆方向で測る。空領域はNAと件数を出し、0で代用しない。

劣化入力Xに対する改善量 MAE_S(X,I)-MAE_S(O,I) も併記し、強度間の難易度差を可視化する。初期誤差がほぼ0なら比率改善は不安定なので、絶対差を主にする。

文字の形状評価は完成注釈があるROIで行う。出力を文字化する評価用の二値化は開発データで固定し、閾値感度を補助資料に示す。p-FMやDRDは二値化評価であり、RGB復元の正確性全体を表す指標として使わない。新しい独自総合点は作らない。

PSNRはRGB uint8/data_range=255。SSIMはgray、window等の設定を記録。LPIPSはAlexNetと入力正規化を固定し、全体縮小版と事前指定した原寸ROIを区別する。縮小版だけでは細い線を評価しにくい。ΔE00はsRGB仮定/D65等の変換条件を記録し、校正された文化財の物理色差とは呼ばない。一次評価の前に出力だけを色合わせ・位置合わせしない。

OCR/CERはくずしじ対応の固定認識器と人手転写を用意できる場合の補助指標。OCRが苦手な文字や学習重複を確認し、OCR向けの濃色化で点が上がったことを原本忠実度と混同しない。可読性を主張するなら、専門家の盲検読解/転写を検討する。実施していない読解改善は主張しない。

### CSCマスクの評価は別表

合成シミ検出のTP/FP/FN、黒/赤文字の混同行列、文字→劣化とシミ→文字の誤分類率を報告する。天然のシミがある領域では合成GTだけで真のFPと断定できないため、確実な陰性ROIで評価する。4強度の非単調性は同一形状条件で再計算し、減少幅とseed変動を示す。「1画素でも下がれば失敗」という判定は避ける。

既存stain-F1は通常のF1ではなく、論文の主指標から外す。閾値15以内の画素率を残す場合は「シミ領域GT近接率」「非シミ領域GT近接率」として分離し、閾値依存性を示す。

## 6. 評価器自体の検証

- I対IでMAE/ΔE00=0、SSIM=1、PSNR=infが期待通りになる。
- 無処理入力の非変更領域誤差が0になる。生成時RGB閾値と評価時OpenCV grayの違いも検出する。
- 細線を消す、偽線を足す、文字を一律濃くする、背景を単色にする、輝度を保って色だけ変える人工例を採点し、対応指標が悪化することを確認する。
- 全白画像が「文字保存良好」と判定されない。
- GT/出力/領域マスクの寸法・stem・向き・色チャネル・極性が一致しない場合は失敗にする。自動リサイズと黙示フォールバックは禁止。
- LPIPS/CIEDE2000は公開された実装仕様・検証データと照合する。

## 7. 統計と判定

- 2ページ試走は有意差検定をしない。80条件を80独立標本として扱わない。
- 主要比較・主指標・文字損傷許容幅を確認実験前に固定する。ページ内の強度・合成seed・拡散seedは反復測定としてまとめる。
- 同一見開き由来のページは見開き単位でまとめる。複数冊では冊別の結果を必ず示し、冊数が少ない段階で母集団全体への推論をしない。
- ページ/見開き単位の対応差と信頼区間を中心にする。階層的な再標本化は十分な冊数がある場合に採用。必要ならWilcoxonを補助に使い、主要な複数比較はHolm補正する。
- seedはまず代表条件で3つ程度確認する。これは十分性の保証ではなく、差が揺らぎに埋もれないかを見る診断。主張する条件では同じ反復設計で確認する。
- 「有意差がない」は「同等」「文字保存に害がない」の証明ではない。文字保存は事前の許容幅と片側信頼区間で判定するか、記述結果に留める。
- 全ページを等重みとする集計と、必要なら画素重み集計を分ける。平均だけでなく中央値、ページ別差、悪化ページ、最悪例も示す。
- 大量の実験を見て良かった条件だけを採用する場合は探索と明記し、独立確認を取り直す。

## 8. 再現性・実装条件

全条件でチェックポイント、入出力寸法、パッチ寸法、overlap、DDRM設定、ACE入力、乱数、赤文字の合成規則を固定する。反復seedを追加する際は内部の固定seed=999を明示設定にし、外側wrapperだけ変えてseedを変更したつもりにならない。

実際に使った参照画像・マスク・各段階出力を保存し、同一条件で画像ハッシュを共有する。評価GTは推論コードから参照できない入出力構造にする。クラスタ数・後処理・閾値・OpenCV/Labのスケール・画素単位の半径を条件表に残す。

原論文相当のマスク、実装バグ修正後の復元器、提案改良を分けて記録する。タイリング・速度修正は全比較に適用し、研究の新規性に含めない。v1は変更しない。

元画像・マスク・重み・推論に依存するソース全体のハッシュ/差分と環境を保存する。既存試走manifestは主要4ファイルだけなので完全な再現記録ではない。再開は出力の存在だけで判定せず、条件ハッシュと正常終了記録を必要とする。例外を捕捉してexit=0にする既存DDRMの挙動には、期待出力の検証を追加する。

出力、一時ファイル、追加キャッシュはすべてプロジェクト配下。既存成果物を上書きしない。

## 9. 新規性と投稿に向けた位置づけ

元論文はすでにCSCの曖昧さ、赤黒文字近傍の誤分類、パッチ境界などを議論している。したがって「CSCに限界がある」だけを新発見として扱わない。新しい証拠は特定の失敗機構、条件依存性、介入実験、文字保全を伴う改善の再現性に置く。

DDNM対DDRMの全面対決は不要。ただし上流DDNMに依存したまま「DDNMは全く不要」と説明しない。古典参照と差がないなら、上流拡散を省いた軽量手法に整理する。下流DDRMにも価値がなければ、拡散を中心に据える理由を再検討する。

先行研究は元npj論文に加え、文字忠実度を扱う拡散復元、文書修復、背景推定、古典inpaintを確認する。参考候補が古文書・くずしじ・劣化条件・入力情報に合うかを確認してから外部ベースラインを1つ以上選ぶ。大きな生成モデルを数だけ追加しない。現時点の検索は新規性を確定する網羅的調査ではない。

比較が完成しても、自動的に強い新手法論文にはならない。既知の弱点に対するパラメータ調整程度なら改良研究として主張を絞る。機構の説明と独立データでの文字保存を示せれば、分析と手法が結びついた論文に近づく。

## 10. 次の実施順序

1. 確定した忠実復元の目的に沿って、基準実装と重みの由来照合、前処理と強調の分離仕様を確定。
2. 小規模注釈ROIと評価器の人工例検証。ここを通るまでは本番を回さない。
3. 2〜4ページ、強度0/0.3/1.0でP0/P1/R1/F0/F1を試す。まず1パス、同一CSC。全工程時間を測る。
4. シミ改善と文字保存が両立したら、CSCの2×2と介入へ。成立しなければ、どの段階が不要/有害かを特定して簡略化。
5. 条件固定後、既存20ページの探索集計と未使用・別冊の確認実験。必要な反復seedを追加。
6. DDNMを最終復元器にした補助実験、外部手法、アブレーション、失敗例を必要範囲で実施。

旧見積もりの1〜2日は旧条件のGPU計算概算であり、注釈・実装修正・確認実験・解析を含む完成時間ではない。新しい総時間は、段階別の実測×件数と注釈時間で見積もり直す。
